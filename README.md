# MoldMaker

MoldMaker is an offline Electron desktop workspace for creating molds from STEP files. The current foundation supports opening a STEP file and validating native project/export file contracts; 3D preview and mold generation are planned for the CAD phase.

## Development

```bash
npm install
npm run dev
```

Useful checks:

```bash
npm run typecheck
npm run lint
npm run test
npm run build
npm run check
```

## Code navigation

The architecture guide is in [docs/architecture.md](docs/architecture.md). Generate the current source dependency graph with:

```bash
npm run codegraph
```

This updates [docs/code-graph/dependencies.json](docs/code-graph/dependencies.json) and [docs/code-graph/dependencies.mmd](docs/code-graph/dependencies.mmd). The graph is generated by Madge from the TypeScript source tree and is useful for tracing imports, renderer/main boundaries, and shared IPC contracts.

## Project layout

```text
src/main/       Electron main process and native file handlers
src/preload/    isolated contextBridge API
src/shared/     IPC channel names, Zod schemas, and shared types
src/renderer/   React UI, Zustand state, styles, and UI primitives
tests/          Vitest contract tests
sample/         sample STEP input
docs/           architecture notes and generated code graph
```
